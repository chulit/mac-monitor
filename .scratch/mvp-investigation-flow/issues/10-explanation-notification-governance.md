# 10: Minimal on-device explanation plus notification governance

**What to build:** optional on-device help that separates facts from hypotheses, with notifications governed so users are informed once, not nagged.

**Blocked by:** 04 (Evidence timeline plus process relevance), 08 (Dashboard plus process tree plus timeline surfaces).

**Status:** ready-for-agent

- [ ] Explanations separate measured facts, temporal correlation, causal hypotheses, uncertainty, and unavailable data
- [ ] Explanations never fabricate metrics, never guarantee causation without evidence, and never perform system actions
- [ ] Core monitoring works fully without on-device AI and without any cloud fallback
- [ ] Notifications follow severity, duration, recurrence, cooldown, deduplication, and recovery, distinguishing normal, active anomaly, and limited observation
